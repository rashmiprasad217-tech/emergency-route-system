About The Project

The Emergency Route System is a final-year web application built to address critical navigation and routing delays during urgent emergencies.

By leveraging real-time browser GPS geolocation and integrating the Google Maps Platform (JavaScript API, Places API, and Directions API), the system dynamically determines a user's position, identifies nearby critical help centres (Hospitals, Police Stations, and Fire Stations), and plots the fastest driving path with exact metrics for distance and transit duration.
